# FACULINK - application Android

Enveloppe Android (WebView) du site https://faculink.xo.je/ .
Pour changer d'adresse, modifier HOME et HOST dans
app/src/main/java/com/faculink/app/MainActivity.java.

## Obtenir l'APK avec GitHub
1. Créer un dépôt sur github.com et y envoyer tout le contenu de ce dossier
   (y compris le dossier caché .github).
2. Onglet Actions : le workflow « Build APK » démarre tout seul (ou « Run workflow »).
3. Quand il est vert (3 à 6 minutes), ouvrir l'exécution puis télécharger FACULINK-apk
   en bas de page (zip contenant FACULINK.apk).
4. Copier FACULINK.apk sur le téléphone et l'installer (autoriser les sources inconnues).

Lien de téléchargement permanent : créer un tag, par exemple v1.0 ; l'APK est alors
joint automatiquement dans l'onglet Releases.
